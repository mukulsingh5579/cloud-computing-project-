# Practical Verification Checklist

- [ ] Docker image builds successfully
- [ ] Flask and Redis containers run
- [ ] Visitor count increments
- [ ] Kubernetes pods become Ready
- [ ] Kubernetes Service responds
- [ ] Metrics Server reports CPU metrics
- [ ] HPA observes metrics and adjusts replicas under load
- [ ] Secondary cluster is independently deployed
- [ ] Traffic failover is tested
- [ ] Redis data consistency is checked
- [ ] Before/after optimization measurements are recorded
- [ ] Screenshots are added to the submission
